# Fruit Island — דף נחיתה + מערכת ניהול

דף נחיתה אחד, RTL מלא, HTML/CSS/JS ללא תלויות בנייה, עם שרת Node/Express
קטן שמגיש את האתר ומספק פאנל ניהול מאובטח בכתובת `/admin`.

## הרצה

```bash
cd ~/Documents/Personal-Projects/fruit-island-landing
npm install
npm start          # http://localhost:8080  (npm run dev לריענון אוטומטי)
```

האתר עצמו ממשיך לעבוד גם בלי השרת — אם `/api/content` לא זמין, הדף מציג את
התוכן שכתוב ב־`index.html` כברירת מחדל.

## פאנל הניהול — `/admin`

### יצירת משתמש ראשון

בפעם הראשונה גשו ל־`http://localhost:8080/admin` — תופנו אוטומטית למסך
ההקמה. **מסך ההקמה זמין רק מהמחשב שעליו רץ השרת (localhost)**, ורק כל עוד
אין אף משתמש. לחלופין, מהטרמינל:

```bash
npm run admin:create      # יצירת משתמש ניהול
npm run admin:passwd      # החלפת סיסמה
```

דרישות סיסמה: לפחות 12 תווים, ולפחות 3 מתוך 4 — אותיות גדולות, קטנות,
ספרות, תווים מיוחדים.

### מה אפשר לערוך

כל התוכן של הדף מחולק ל‑15 מקטעים בתפריט הצד: כללי ו‑SEO, פרטי קשר, מסך
פתיחה, פס נע, המיצג המרכזי, גלריה, מה מזמינים, סוגי אירועים, איך מזמינים,
למה אנחנו, ביקורות, אזורי משלוח, שאלות נפוצות, טופס הצעת מחיר ופוטר.
ניתן לערוך טקסטים, לינקים, טלפונים, להוסיף/למחוק/לסדר מחדש פריטים ברשימות
(גלריה, אירועים, שאלות נפוצות, ביקורות…), ולהחליף תמונות וסרטונים.

### מדיה

"ספריית מדיה" מאפשרת העלאה של תמונות (JPG/PNG/WebP/GIF/AVIF, עד 8MB)
וסרטונים (MP4/WebM, עד 80MB). הקבצים נשמרים ב־`assets/images/uploads/`
ו־`assets/video/uploads/`. סוג הקובץ נבדק לפי החתימה הבינארית ולא לפי
הסיומת, ו‑SVG נחסם בכוונה. אי אפשר למחוק קובץ שנמצא בשימוש בדף.

### גיבויים

כל שמירה יוצרת גיבוי אוטומטי ב־`server/data/backups/` (20 אחרונים).
ב"גיבויים והגדרות" אפשר לשחזר גיבוי, לחזור לתוכן ברירת המחדל ולהחליף סיסמה.

### אבטחה

- סיסמאות עם `scrypt` (מלח אקראי, השוואה בזמן קבוע)
- Session בעוגייה `HttpOnly` + `SameSite=Strict`, מזהה מתחלף בכל התחברות,
  תוקף 12 שעות / שעתיים חוסר פעילות, קשור ל‑User‑Agent
- הגנת CSRF (double‑submit token) + בדיקת `Origin`/`Referer` בכל כתיבה
- הגבלת קצב התחברות: 5 ניסיונות ל‑15 דקות לכל IP, ואז נעילה זמנית
- כל שמירה עוברת ולידציה מול סכימה — שדות לא מוכרים נזרקים, כתובות מוגבלות
  ל‑`http/https/mailto/tel`, נתיבי מדיה מוגבלים לתיקיות ההעלאה
- הטמעת תוכן בדף נעשית רק דרך `textContent` — אין `innerHTML`
- CSP קשיח (ללא `unsafe-inline` לסקריפטים), HSTS בפרודקשן, `noindex` ל־`/admin`
- השרת מגיש רק את `index.html`, `assets/` ו‑`admin/` — תיקיית `server/`
  (כולל קובץ המשתמשים) לעולם לא נחשפת

### פרודקשן

העתיקו `.env.example` ל־`.env` והגדירו:

```env
NODE_ENV=production
PORT=8080
PUBLIC_ORIGIN=https://fruitisland.co.il
TRUST_PROXY=1        # אם רצים מאחורי Nginx/Cloudflare
FORCE_SECURE_COOKIE=true
```

חובה להריץ מאחורי HTTPS. את `server/data/` ואת תיקיות ההעלאה יש לגבות.

```
server/lib/schema.js       הסכימה — מקור האמת לשדות שניתן לערוך
server/lib/content.js      קריאה, ולידציה, שמירה וגיבוי של התוכן

server/data/content.json   התוכן החי (לא ב־git)
server/data/users.json     משתמשי הניהול (לא ב־git)
```
